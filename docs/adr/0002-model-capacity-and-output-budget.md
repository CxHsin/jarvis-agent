# 按模型维护容量并使用完整窗口

DeepSeek 官方模型列表不提供窗口容量，模型别名对应的服务能力也可能变化，因此按供应商和模型维护可更新的能力配置，记录官方来源与核对日期，允许显式覆盖；未知模型不套用统一默认容量，需要补充配置。使用当前模型完整上下文窗口，不另设较小使用预算；为单次输出与估算误差预留空间，缓存命中的输入仍计入窗口。单次输出默认上限为 32K token，可配置且受模型输出上限约束，避免按服务最大输出能力预留过多空间。

安全余量初始取模型窗口的 2%，支持配置；这是吸收输入估算误差的起点，不是已验证的误差上界。预计输入量加单次输出上限及安全余量严格超过窗口的 90% 时触发压缩，压缩后输入量目标为可用输入预算的 80%，目标比例支持配置。可用输入预算等于窗口减去单次输出上限和安全余量；若服务另有输入上限，还需受该上限约束。这在预留输出和估算误差之外再留出 10% 窗口缓冲，降低接近硬上限时的失败风险。

它扩展 ADR 0001 的容量来源，并替代其中的 86% 触发、65% 目标规则。本轮不实施跨会话记忆。
