# 项目内凭据采用本地信任模型

Jarvis 允许从启动工作区内的 `.env` 加载模型密钥和 Telegram Bot Token；不再因存在 `.env` 拒绝文件工具或 Windows 沙箱内的 `bash`。这样符合本地 Pi 式使用方式，避免强迫用户移动常规项目配置。此决策**仅替代 ADR 0015 对工作区内 `.env` 必须不可由工具读取、Token 绝不进入模型上下文/会话的承诺**；工作区边界、状态目录保护、Telegram 单用户身份、AppContainer 失败关闭和不自动重放等其他契约仍有效。

代价是模型驱动的 `read`/`bash` 可以读取工作区内的 `.env`，读取结果可能发送给模型服务并持久写入会话；输出中替换已知 Token 只是降低误回显，不能作为保密边界。`.gitignore` 只避免意外提交，不控制工具访问。只应在信任当前工作区、内容来源和模型服务时使用；需要机密性时，应把凭据放在工具不可访问的工作区外，或改用经过验证的 OS 级隔离。保留明确风险提示，而不是宣称项目内 Token 已被沙箱隐藏。
