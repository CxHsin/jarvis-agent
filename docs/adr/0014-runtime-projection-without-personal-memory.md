# 以运行事件和模型上下文投影为核心，暂撤个人记忆

Jarvis 当前优先稳定单会话 Agent 的模型—工具运行时。会话只追加事件是完整交互的事实源；模型上下文是从事件得到的可见投影，近期选择、压缩 checkpoint 与预算属于该投影，不由个人记忆的 Recent 窗口间接决定。旧事件中已发生的记忆工具调用仍是历史事实，但新任务不再提供个人事实、画像、记忆工具、提取或召回。选择暂撤个人记忆而不是继续维护 History/Recent/Pending 与事实库，是为了在运行时边界尚未稳定时避免双重来源和耦合；本决定接替 ADR 0006、0011、0012 中关于当前产品记忆能力的决策，保留 ADR 0008、0009 关于原始事件与恢复的契约。

未来会话继续记录事件并可恢复；既有本机状态数据的清理与代码改造分开执行。清理前逐项核对当前配置状态目录的路径和内容，不递归删除状态根目录，也不影响其他工作区。旧会话数据一旦清理，无法再恢复；清理不是 runtime 启动时的自动行为。
