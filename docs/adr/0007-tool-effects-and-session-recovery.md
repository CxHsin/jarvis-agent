# 工具副作用发生后保留会话证据

ADR 0003 的整轮回滚适用于尚未执行工具的请求；一旦工具已开始执行，后续模型失败不再回滚该任务的消息、结果与审计，因为文件写入、命令及外部操作无法靠截断会话日志撤销。缺失结果的恢复占位改为「执行状态未知」，不声称未执行，也不自动重放；权限收紧、撤销和供应商回退决定独立于对话回滚而持久保留。

工具定义在注册后按版本不可变，动态定义通过搜索结果追加到固定前缀之后，并独立保留历史版本以跨压缩和重启核对；只有当前任务激活的版本能执行。代价是失败任务仍可能留在上下文中，合作取消之外的 Python 扩展超时可能产生未知结果，必须保留资源占用并由宿主核对，不能自动重试以换取表面上的完整回答。
