# 会话内上下文管理与阈值压缩

上下文管理由独立的层维护：稳定的系统提示与工具定义保持在消息前缀，证据索引与上下文预算由代码在进程内维护，不再作为动态状态注入每轮请求；会话内保留原始工具结果归档，但不跨进程持久化。上下文估算达到窗口的 86%（可配置）时，批量把旧工具结果替换为带来源引用的摘要，目标降至约 65%；压缩模型可通过 `COMPRESSION_MODEL` 指定，未配置时复用主模型。窗口大小遵循显式 `CONTEXT_WINDOW_TOKENS` 优先、上游模型元数据其次的顺序；元数据缺失时不猜测。选择这一方案是为了在不破坏 Chat Completions 工具消息配对的前提下，控制上下文膨胀并保留可审计证据。每轮状态栏注入被有意移除，理由与对照见 `docs/research/agent-status-bar-survey.md`；Skills、跨会话记忆和真实 Prompt Cache 测量留待后续迭代。
